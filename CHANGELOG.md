# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-10-27

### Added

- Local DeepSeek chat, search, fetch, and search-enhanced answer modes.
- SSE streaming and reasoning output.
- Search source space tree with domain grouping and expandable nodes.
- Right-side settings drawer with close, backdrop, and Escape support.
- Connection testing and model selection from the `/models` response.
- Automatic browser opening and port fallback for the Windows executable.
- GitHub Actions release workflow for Windows EXE artifacts.
